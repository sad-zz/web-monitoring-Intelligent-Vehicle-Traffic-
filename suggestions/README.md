# پوشه پیشنهادات (Suggestions)

این پوشه شامل نسخه بهبودیافته اپلیکیشن **سامانه مدیریت ترافیک هوشمند** است.
فایلهای اصلی پروژه دستنخورده باقی ماندهاند.

## تغییرات نسبت به نسخه اصلی

### رفع باگها

- ✅ رفع نمایش غلط `renderTableInfo` در حالت بدون نتیجه
- ✅ افزودن جستجو بر اساس `deviceCode` در دستگاهها
- ✅ رفع نمایش وضعیت محورها در جدول خانه (warning/offline/error)
- ✅ رفع Auth Guard (رندر نشدن داده قبل از تأیید session)

### بهبودها

- 🆕 Toast notification بهجای `alert()`
- 🆕 دکمه ویرایش برای محورها و دستگاهها
- 🆕 لاگین استاتیک برای پیشنمایش بدون backend
- 🆕 نمودار خلاصه وضعیت محورها در صفحه خانه

## پیشنمایش روی Vercel

۱. این پوشه را روی Vercel آپلود کنید
۲. با نام کاربری `admin` و رمز `admin1234` وارد شوید
۳. همه امکانات قابل بررسی است

> **نکته:** در این نسخه backend وجود ندارد. دادهها از `data/devices.js` بارگذاری میشوند.
