# tc-relay

سیستم دریافت داده از دستگاه‌های شمارنده ترافیک (پروتکل RATCX1) و ارسال خودکار به سامانه RMTO (RAHSAM).

---

## پیش‌نیازها

- Node.js نسخه ۱۶ یا بالاتر
- دسترسی شبکه به پورت ۲۰۲۲ (TCP)
- اطلاعات اتصال سامانه RMTO (CID, UID, PWD, URL)

---

## نصب

```bash
cd tc-relay
npm install
```

---

## تنظیمات

فایل `config.js` را ویرایش کنید:

| کلید | توضیح | پیش‌فرض |
|------|-------|---------|
| `TCP_PORT` | پورت TCP دستگاه‌ها | `2022` |
| `RMTO_URL` | آدرس کامل سرویس SOAP | باید پر شود |
| `CID` | شناسه شرکت | باید پر شود |
| `UID` | نام کاربری | باید پر شود |
| `PWD` | رمز عبور | باید پر شود |
| `ROUTE_MAP` | نگاشت sysId → RID | باید پر شود |

### نمونه ROUTE_MAP

```js
ROUTE_MAP: {
  '00000001': 'R001',
  '00000002': 'R002',
},
```

## اجرا

## لاگ‌ها

لاگ‌ها در پوشه `logs/` ذخیره می‌شوند، یک فایل به ازای هر روز:

```
logs/
  2025-01-15.log
  2025-01-16.log
```

سطوح لاگ: `INFO`, `CONN`, `RECV`, `SEND`, `DATA`, `RMTO`, `ACK`, `WARN`, `ERR`, `FATAL`

## چرخه کار

```
دستگاه → 8000 (handshake)
سرور   → 0012 (time-sync × 2، فاصله 3 ثانیه)
دستگاه → 8012 (ACK)
سرور   → 0197 × 3 (درخواست 3 interval آخر)
دستگاه → 8821 × 3 (داده intervals)
سرور   → Add5 SOAP به RMTO برای هر interval

هر 5 دقیقه: سرور → 0197 (interval جدید)
هر 15 دقیقه: سرور → 0012 (time-sync مجدد)
```
