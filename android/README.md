# اپلیکیشن اندروید TC Manager

اپ اندرویدی مانیتورینگ و مدیریت دستگاه‌های تردد شمار **RATCX1** — مکمل موبایلی پنل وب همین مخزن.

## امکانات

| تب | توضیح |
|----|-------|
| **داشبورد** | نمایش کامل پنل وب مانیتورینگ (همین سایت) داخل اپ |
| **دستگاه‌ها** | لیست بومی وضعیت دستگاه‌ها از API سرور (`/api/devices` + `/api/tcp/connected`) با نشانگر آنلاین/آفلاین، اتصال زنده TCP و دکمه «تنظیم ساعت» و «درخواست داده» برای دستگاه‌های متصل |
| **راهداری** | سایت RMTO داخل اپ + دکمه **ورود خودکار** با نام کاربری/رمز ذخیره‌شده (برای دیدن لیست دستگاه‌های آنلاین در سامانه راهداری) |
| **ترمینال** | ترمینال سریال RATCX1 با دو حالت **USB (کابل)** و **WiFi (ESP01)** + دکمه‌های سریع همه فرمان‌های فریم‌ور + رمزگشای فارسی کدهای خطا |
| **تنظیمات** | آدرس پنل، اطلاعات ورود سرور و راهداری، باودریت، آدرس/پورت ESP01 |

## ساخت (Build)

پروژه Gradle استاندارد است — با **Android Studio** باز کنید:

1. Android Studio → `Open` → پوشه `android/` همین مخزن
2. صبر کنید Gradle Sync تمام شود (نیاز به اینترنت برای دانلود کتابخانه‌ها)
3. `Build > Build APK(s)` یا اجرای مستقیم روی گوشی

یا از خط فرمان (با Android SDK نصب‌شده):

```bash
cd android
gradle assembleDebug
# خروجی: app/build/outputs/apk/debug/app-debug.apk
```

- حداقل اندروید: **7.0 (API 24)**
- کتابخانه سریال: [usb-serial-for-android](https://github.com/mik3y/usb-serial-for-android) (پشتیبانی FTDI، CH340، CP210x، PL2303، CDC)

## ترمینال USB (حالت کابل)

1. مبدل USB به سریال (TTL) را به UART1 دستگاه وصل کنید (115200 8N1)
2. مبدل را با کابل OTG به گوشی بزنید — اپ خودش مجوز USB می‌گیرد
3. تب ترمینال → حالت «USB» → اتصال
4. فرمان‌ها را تایپ کنید (مثلاً `0088`) یا از دکمه‌های سریع استفاده کنید

فهرست کامل فرمان‌ها و معنی خطاها: [`docs/serial-protocol.md`](../docs/serial-protocol.md) — همین فهرست داخل اپ هم هست (دکمه «فرمان‌ها»).

## حالت WiFi با ماژول ESP01 (طرح آینده)

به‌جای کابل، یک ماژول **ESP-01 (ESP8266)** به هدر سریال میکروی اصلی وصل می‌شود و اپ از طریق TCP همان ترمینال را بی‌سیم در اختیار می‌گذارد:

```
میکروی اصلی (dsPIC)          ESP-01
UART1 TX  ────────────────►  RX
UART1 RX  ◄────────────────  TX
GND       ─────────────────  GND
3.3V      ─────────────────  VCC + CH_PD
```

**نکات سخت‌افزاری:**
- ESP-01 فقط با **۳.۳ ولت** کار می‌کند؛ اگر UART میکرو ۵ ولتی است، مقسم ولتاژ روی خط RX ماژول لازم است.
- مصرف لحظه‌ای ESP تا ~۳۰۰ میلی‌آمپر است — رگولاتور ۳.۳V جدا توصیه می‌شود.

**فریم‌ور پیشنهادی ماژول:** یک پل شفاف TCP↔UART مثل [ESP-Link](https://github.com/jeelabs/esp-link) یا اسکچ ساده `WiFiTelnetToSerial` (نمونه رسمی Arduino-ESP8266):
- باودریت پل: **115200** (مطابق UART1 فریم‌ور)
- حالت AP: ماژول شبکه‌ای مثل `TC-XXXX` می‌سازد؛ گوشی به آن وصل می‌شود و آدرس پیش‌فرض `192.168.4.1` پورت `23` در تنظیمات اپ آماده است
- حالت Station: ماژول به مودم/روتر محل وصل می‌شود و IP آن را در تنظیمات اپ وارد می‌کنید

چون پل شفاف است، **تمام فرمان‌های حالت کابل (0088، 0006، 0012 و…) بدون هیچ تغییری از داخل اپ کار می‌کنند** و بعداً همین بستر برای رابط وب‌بیس هم قابل استفاده است (ESP-Link خودش صفحه وب هم دارد).

## امنیت

- اطلاعات ورود فقط در حافظه خصوصی اپ (`SharedPreferences` با `MODE_PRIVATE`) روی همان گوشی ذخیره می‌شود و جایی ارسال نمی‌شود (جز خود سرور/سایت مربوطه هنگام ورود).
- ارتباط با سرور پروژه و سایت RMTO مطابق وضعیت فعلی آن‌ها HTTP است؛ به همین دلیل `network_security_config` ترافیک cleartext را مجاز کرده است.
