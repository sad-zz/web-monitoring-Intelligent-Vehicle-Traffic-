# کدهای خطای دستگاه RATCX1

> منبع: فایل `firmware (3).rar` → `firmware/Main/Variables.h`  
> مدل دستگاه: `RATCX1` — نسخه: `HW:B-06, SW:JA11`

---

## ساختار فیلد خطا در پیام ۸۸۲۱

در پایان هر بسته داده‌ای که دستگاه ارسال می‌کند (پیام `8821`)، یک عدد ۴ رقمی به نام `error_byte` قرار دارد:

```
موقعیت [258-261] از رشته interval_data → error_byte (4 کاراکتر، عدد صحیح)
```

این عدد یک **bitmask** است — هر بیت نشان‌دهنده یک خطای مستقل است و خطاها می‌توانند همزمان فعال باشند.

---

## جدول بیت‌های خطا

| بیت | مقدار دسیمال | نام ثابت | توضیح |
|-----|--------------|----------|--------|
| 0 | **1** | `MMC_ERR` | خطای کارت حافظه (SD/MMC) — ذخیره داده روی کارت ناموفق |
| 1 | **2** | `LP1_ERR` | خطای لوپ ۱ — سیم‌پیچ مدفون زیرجاده شماره ۱ |
| 2 | **4** | `LP2_ERR` | خطای لوپ ۲ — سیم‌پیچ مدفون زیرجاده شماره ۲ |
| 3 | **8** | `LP3_ERR` | خطای لوپ ۳ — سیم‌پیچ مدفون زیرجاده شماره ۳ |
| 4 | **16** | `LP4_ERR` | خطای لوپ ۴ — سیم‌پیچ مدفون زیرجاده شماره ۴ |
| 5 | **32** | `VMN_ERR` | خطای ولتاژ حداقل شبانه — سولار شبانه زیر حد مجاز |
| 6 | **64** | `SOL_ERR` | خطای پنل خورشیدی — تولید انرژی در روز ناکافی |
| 7 | **128** | `LBT_ERR` | خطای باتری ضعیف — ولتاژ باتری زیر آستانه |
| 8 | **256** | `L1D_ERR` | خطای جهت لاین ۱ |
| 9 | **512** | `L2D_ERR` | خطای جهت لاین ۲ |

---

## رمزگشایی نمونه‌های واقعی

| کد دریافتی | هگز | بیت‌های فعال | خطاهای فعال |
|------------|-----|--------------|-------------|
| **24** | `0x0018` | بیت ۳ + ۴ | LP3_ERR + LP4_ERR — لوپ ۳ و ۴ خراب |
| **20** | `0x0014` | بیت ۲ + ۴ | LP2_ERR + LP4_ERR — لوپ ۲ و ۴ خراب |
| **30** | `0x001E` | بیت ۱+۲+۳+۴ | LP1_ERR + LP2_ERR + LP3_ERR + LP4_ERR — همه لوپ‌ها خراب |
| **32** | `0x0020` | بیت ۵ | VMN_ERR — ولتاژ سولار شبانه پایین |
| **88** | `0x0058` | بیت ۳+۴+۶ | LP3_ERR + LP4_ERR + SOL_ERR — لوپ ۳ و ۴ خراب + مشکل سولار |

## منطق تشخیص خطا در فریم‌ور

### خطاهای لوپ (LP1–LP4)
```c
// اگر لوپ هنگام calibration پاسخ ندهد → خطا ست می‌شود
if (loop_error_tmp == 0)
    set_error(LP3_ERR);
// وقتی دوباره پاسخ داد → خطا پاک می‌شود
else
    reset_error(LP3_ERR);
```
**علت رایج:** قطع/آسیب سیم‌پیچ مدفون در آسفالت، یا اتصال ضعیف کانکتور.

### خطای باتری (LBT_ERR)
```c
if (vbat < 230) set_error(LBT_ERR);
else reset_error(LBT_ERR);
```
آستانه: مقدار خام ADC < 230 (معادل تقریباً ۱۱.۵ ولت)

### خطای پنل خورشیدی (SOL_ERR)
```c
if (current_time.hour > 10 && current_time.hour < 14 && solar < 200)
    set_error(SOL_ERR);
if (solar > 250) reset_error(SOL_ERR);
```
ساعت ۱۱–۱۴، مقدار سولار زیر ۲۰۰ → پنل در ساعت اوج آفتاب شارژ کافی ندارد.

### خطای ولتاژ شبانه (VMN_ERR)
```c
if (current_time.minute == 30 && current_time.hour == 22 && solar < 200)
    set_error(VMN_ERR);
if (solar > 250) reset_error(VMN_ERR);
```
ساعت ۲۲:۳۰، اگر ولتاژ ذخیره‌شده کافی نباشد.

## نحوه بررسی سریع یک کد خطا

برای تجزیه یک کد خطا، آن را به باینری تبدیل کنید:

```
خطا=24 → باینری: 0000 0001 1000
                           ↑↑
                      بیت3=LP3  بیت4=LP4
```

یا با JavaScript:
```js
const ERROR_BITS = {
  1:   'MMC_ERR  - خطای کارت حافظه',
  2:   'LP1_ERR  - خطای لوپ ۱',
  4:   'LP2_ERR  - خطای لوپ ۲',
  8:   'LP3_ERR  - خطای لوپ ۳',
  16:  'LP4_ERR  - خطای لوپ ۴',
  32:  'VMN_ERR  - خطای ولتاژ شبانه',
  64:  'SOL_ERR  - خطای پنل خورشیدی',
  128: 'LBT_ERR  - خطای باتری ضعیف',
  256: 'L1D_ERR  - خطای جهت لاین ۱',
  512: 'L2D_ERR  - خطای جهت لاین ۲',
};

function decodeError(code) {
  return Object.entries(ERROR_BITS)
    .filter(([bit]) => (code & parseInt(bit)) !== 0)
    .map(([, name]) => name);
}
```
