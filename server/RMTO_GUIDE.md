# راهنمای یکپارچه‌سازی با RMTO
# RMTO Integration Guide

## 🔗 اتصال به سرویس RMTO

سرویس RMTO (سازمان راهداری و حمل و نقل جاده‌ای) از طریق SOAP Web Service در دسترس است:

**آدرس WSDL:**
```
http://otf.rmto.ir/Companies/Companies.asmx?WSDL
```

**متدهای موجود:**
- `AddData` - ارسال داده ساده (تعداد کل + میانگین سرعت)
- `AddData5` - ارسال داده 5 کلاسه (تفکیک وسیله نقلیه و سرعت)
- `AddData8` - ارسال داده 8 کلاسه (تفکیک دقیق‌تر)

## 📋 پیش‌نیازها

### 1. اطلاعات احراز هویت

برای استفاده از سرویس نیاز به موارد زیر دارید:

```env
RMTO_COMPANY_CODE=58        # کد شرکت
RMTO_USERNAME=NOGSH         # نام کاربری
RMTO_PASSWORD=your_password # رمز عبور
```

این اطلاعات را در فایل `.env` قرار دهید.

### 2. نصب وابستگی‌ها

```bash
cd server
npm install
```

## 🧪 تست اتصال

### روش 1: اسکریپت خط فرمان

```bash
cd server
node test-rmto.js
```

این اسکریپت:
- اتصال به WSDL را بررسی می‌کند
- ساختار سرویس را نمایش می‌دهد
- یک درخواست آزمایشی AddData5 ارسال می‌کند
- پاسخ و خطاهای احتمالی را نمایش می‌دهد

### روش 2: رابط وب

1. سرور را راه‌اندازی کنید:
```bash
cd server
npm start
```

2. به آدرس زیر بروید:
```
http://localhost:3000/test-rmto.html
```

3. فرم تست را پر کنید و ارسال کنید

## 📊 فرمت داده AddData5

### پارامترهای ورودی:

| پارامتر | نوع | توضیحات | مثال |
|---------|-----|---------|------|
| `CompanyCode` | string | کد شرکت | "58" |
| `UserName` | string | نام کاربری | "NOGSH" |
| `Password` | string | رمز عبور | "..." |
| `StationCode` | string | کد ایستگاه (4 رقمی) | "1001" |
| `DateTime` | string | تاریخ و زمان | "2024/02/22 14:30" |
| `C1` | int | کلاس 1 - سواری | 10 |
| `C2` | int | کلاس 2 - وانت | 20 |
| `C3` | int | کلاس 3 - مینی‌بوس | 15 |
| `C4` | int | کلاس 4 - اتوبوس | 5 |
| `C5` | int | کلاس 5 - کامیون | 3 |
| `S1` | int | سرعت < 60 | 12 |
| `S2` | int | سرعت 60-80 | 18 |
| `S3` | int | سرعت 80-100 | 15 |
| `S4` | int | سرعت 100-120 | 8 |
| `S5` | int | سرعت > 120 | 0 |
| `Violation` | int | تعداد تخلفات | 2 |
| `Speed` | int | میانگین سرعت | 85 |

### فرمت تاریخ و زمان

**صحیح:** `YYYY/MM/DD HH:mm`

مثال‌های صحیح:
- `2024/02/22 14:30`
- `2024/12/31 23:59`
- `2024/01/01 00:00`

مثال‌های غلط:
- ❌ `2024-02-22 14:30` (خط تیره به جای اسلش)
- ❌ `22/02/2024 14:30` (ترتیب اشتباه)
- ❌ `2024/2/22 14:30` (ماه و روز باید دو رقمی باشند)

## 🔧 عیب‌یابی خطاهای رایج

### خطا: "Failed to create SOAP client"

**علت:** عدم دسترسی به WSDL

**راه حل:**
1. اتصال اینترنت را بررسی کنید
2. دسترسی به `otf.rmto.ir` را تست کنید:
   ```bash
   curl http://otf.rmto.ir/Companies/Companies.asmx?WSDL
   ```
3. فایروال را بررسی کنید

### خطا: "Authentication failed" یا "401 Unauthorized"

**علت:** اطلاعات احراز هویت اشتباه

**راه حل:**
1. `RMTO_USERNAME` و `RMTO_PASSWORD` را بررسی کنید
2. با سازمان تماس بگیرید و اعتبار حساب را تأیید کنید
3. `RMTO_COMPANY_CODE` را بررسی کنید

### خطا: "Invalid DateTime format"

**علت:** فرمت تاریخ اشتباه است

**راه حل:**
- از فرمت `YYYY/MM/DD HH:mm` استفاده کنید
- ماه و روز باید دو رقمی باشند (01, 02, ..., 12)
- ساعت و دقیقه باید دو رقمی باشند (00, 01, ..., 59)

### خطا: "StationCode not found"

**علت:** کد ایستگاه در سیستم RMTO ثبت نشده

**راه حل:**
1. کد ایستگاه را با سازمان راهداری تأیید کنید
2. مطمئن شوید کد 4 رقمی است
3. کد ایستگاه را در سیستم RMTO ثبت کنید

## 📝 لاگ‌ها و مانیتورینگ

### مشاهده لاگ‌های ارسال

```bash
# در کنسول سرور
[RMTO] AddData5 request: {...}
[RMTO] AddData5 response: {...}
[RMTO] AddData5 error: ...
```

### API endpoint‌های لاگ

```bash
# دریافت آخرین لاگ‌ها
GET /api/rmto/logs?limit=50

# دریافت صف ارسال نشده
GET /api/rmto/queue?type=5class

# ارسال مجدد داده‌های ناموفق
POST /api/rmto/retry
```

### دیتابیس

لاگ‌ها در جدول `send_log` ذخیره می‌شوند:

```sql
SELECT * FROM send_log 
WHERE success = 0 
ORDER BY created_at DESC 
LIMIT 50;
```

## 🔄 ارسال خودکار

سیستم هر 15 دقیقه به صورت خودکار:
1. داده‌های خام را جمع‌آوری می‌کند
2. آن‌ها را در جداول `rmto_queue` و `rmto_queue_5class` ذخیره می‌کند
3. داده‌های ارسال نشده را به RMTO ارسال می‌کند

برای تغییر فاصله زمانی:

```env
SEND_INTERVAL_MINUTES=15
```
